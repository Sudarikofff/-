Сборка «Личный состав» 1.1.0 для Windows

1. Установите Python 3.12 (64 бита), включая Python Launcher и Tcl/Tk:
   https://www.python.org/downloads/release/python-31210/
2. Распакуйте проект в папку, доступную для записи.
3. Запустите build_windows.bat и дождитесь сообщения Ready.

Для установки библиотек требуется интернет. Скрипт создаёт отдельное окружение,
запускает автоматические проверки и собирает приложение. Готовая программа появится здесь:

windows-dist/Discipline_PS_FSB/Discipline_PS_FSB.exe

Переносите всю папку Discipline_PS_FSB, включая _internal. На компьютере,
где запускается готовая программа, Python не требуется.

База с персональными данными в сборку не входит. При первом запуске программа
создаст новую базу database/discipline.db рядом с exe. Чтобы продолжить работу
с существующими данными, закройте программу и скопируйте файл базы в папку
database рядом с exe. Для проверки используйте копию базы: при запуске программа
может обновить её структуру.

Исходную установленную программу сборка не заменяет. Кнопки, календари, меню
и экспорт Word проверьте после запуска готовой программы на Windows.
