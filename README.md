# Личный состав · версия 1.1.0

«Личный состав» — настольная программа для ведения сведений о военнослужащих. Она хранит данные в локальной базе SQLite и помогает работать с личными карточками, служебной историей, дисциплинарной практикой и сроками.

## Что умеет программа

- Вести личные данные, сведения о службе, семье, образовании, транспорте и кредитах.
- Хранить поощрения и взыскания, связывать снятие взыскания с конкретной записью.
- Показывать сроки документов, контрактов, аттестаций, ОСАГО и платежей.
- Напоминать об окончании ОСАГО и позволять отложить уведомление.
- Искать и сортировать записи, копировать данные из таблиц и сохранять карточку в Word.

## Запуск на Linux

Понадобится Python 3.12 или новее и Tkinter. В Arch Linux установите пакет `tk`, если он ещё не установлен.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Сборка для Windows

На компьютере с Windows установите Python 3.12 разрядности 64 бит, включая Python Launcher и Tcl/Tk. Подключение к интернету потребуется для установки библиотек.

Запустите `build_windows.bat`. Скрипт создаст окружение для сборки, установит зависимости, выполнит автоматические проверки и соберёт программу. Готовый файл появится здесь:

```text
windows-dist/Discipline_PS_FSB/Discipline_PS_FSB.exe
```

Переносите на другой компьютер всю папку `Discipline_PS_FSB`, включая подпапку `_internal`. Устанавливать Python на компьютере, где запускается готовая сборка, не нужно.

## Данные и резервные копии

При первом запуске программа создаёт базу `database/discipline.db`. База хранится на этом компьютере и не входит в сборку Windows. Для переноса данных закройте программу и скопируйте файл базы в папку `database` рядом с исполняемым файлом.

Перед изменением структуры существующей базы программа создаёт резервную копию в `backup/`. Для работы с другой базой задайте переменную окружения `DISCIPLINE_DB_PATH`.

Личные базы, резервные копии, временные файлы и результаты сборки исключены из Git. Не добавляйте в репозиторий настоящие персональные данные.

## Запуск проверок

```bash
python -m unittest discover -s tests -v
```

Проверки используют временные базы и не изменяют пользовательскую базу. Для оконной части приложения нужен графический рабочий стол.
